# FlowCast
## AI-Powered Smart Traffic Flow Prediction Platform

### 1. Project Overview
FlowCast is an AI-powered traffic analytics and prediction platform designed to analyse traffic patterns and predict important traffic conditions.

The platform uses historical traffic sensor data, weather information and calendar data to support better traffic monitoring and decision-making.

### 2. Problem Statement
Traffic congestion, increasing travel time and road accidents create challenges for urban transportation systems.

FlowCast aims to analyse traffic information and generate predictions that can help identify potential traffic problems.

### 3. Project Objectives
- Analyse traffic sensor datasets.
- Study traffic patterns across different roads and time periods.
- Analyse the impact of weather conditions on traffic.
- Predict traffic volume.
- Predict congestion levels.
- Estimate travel time.
- Classify accident risk.
- Develop an interactive Streamlit dashboard.

### 4. Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Streamlit
- Joblib
- Jupyter Notebook
- Visual Studio Code

### 5. Machine Learning Models
FlowCast includes four prediction models:
- Traffic Volume Prediction
- Traffic Congestion Prediction
- Travel Time Prediction
- Accident Risk Prediction

Random Forest is used for the machine learning implementation.

### 6. Project Structure

### 8. How to Run the Project

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit dashboard:

```bash
streamlit run dashboard/app.py
```
